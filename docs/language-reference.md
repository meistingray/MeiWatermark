# MeiWatermark language reference

The application uses `src/meiwatermark/i18n.py` as the single source for visible interface wording. Chinese is the default language; English, Spanish, and Japanese are selected from the **Language** menu.

| 中文 | English | Español | 日本語 |
| --- | --- | --- | --- |
| 打开图片 | Open Images | Abrir imágenes | 画像を開く |

| 添加文字水印 | Add Text Watermark | Añadir marca de texto | テキスト透かしを追加 |
| 水印预设 | Watermark Preset | Preajuste de marca | 透かしプリセット |
| 导出预设 | Export Preset | Preajuste de exportación | 書き出しプリセット |
| 水印图层 | Watermark Layers | Capas de marca | 透かしレイヤー |
| 选中图层属性 | Selected Layer | Capa seleccionada | 選択中のレイヤー |
| 大小 / 透明度 / 旋转 | Size / Opacity / Rotation | Tamaño / Opacidad / Rotación | サイズ / 不透明度 / 回転 |
| 水平内嵌 / 垂直内嵌 | Horizontal / Vertical | Horizontal / Vertical | 横方向 / 縦方向 |
| 九宫格定位 | Anchor Position | Posición de anclaje | アンカー位置 |
