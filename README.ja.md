MeiWatermark は、複数レイヤーの透かしと、異なるサイズの画像でも一貫した見た目の比率・位置を扱える、オープンソースのデスクトップ一括透かし入れツールです。

画像・文字の透かしを重ねて並べ替え、九点グリッド配置、内側余白、不透明度、回転、文字の輪郭、再利用可能なプリセットを設定できます。

JPEG、PNG、WebP の一括書き出しに対応し、品質、リサイズ制限、ファイルサイズの見積もり、相対出力パスを指定できます。

## 主な機能

- **複数レイヤーの透かし**：複数の画像・文字レイヤーを組み合わせ、表示切替、並べ替え、ドラッグ操作ができます。
- **一貫した視覚効果**：透かしサイズは画像の短辺に対する % またはピクセルで指定できます。文字透かしでは、サイズはフォントサイズではなく、描画後の文字全体の長辺を示します。
- **詳細な配置**：九点グリッドのアンカー、横方向・縦方向の内側余白、不透明度、回転を個別に調整できます。内側余白には負の値も使用できます。
- **文字透かし**：ローカライズされたシステムフォント一覧を利用し、文字色と輪郭色を別々に設定できます。色なしや輪郭の太さにも対応します。
- **全画面透かし**：画像または文字の透かしを写真全体に繰り返し配置できます。間隔は短辺に対する % で指定し、千鳥配置にも対応します。
- **ライブプレビュー**：作業中に結果を確認できます。画像をウィンドウ内の任意の場所にドラッグして読み込むと、最後に追加した画像が自動的に選択され表示されます。
- **写真一覧の管理**：`Delete` キー、コンテキストメニュー、または **一覧をクリア** で現在の一覧から画像を外せます。元ファイルは削除されません。
- **一括書き出し**：JPEG、PNG、WebP に対応。品質の既定値は 100 で、長辺・短辺・倍率によるリサイズ制限を任意に設定できます。
- **出力管理**：書き出し前に現在の画像のファイルサイズを見積もります。EXIF と ICC プロファイルの保持、各元画像を基準とした相対出力パスに対応します。
- **プリセット管理**：プリセットごとに透かしレイヤーと書き出し設定を独立した JSON ファイルに保存します。
- **ローカル処理**：画像の読み込み、プレビュー、書き出しはクラウドサービスを使わずローカルで実行します。
- **多言語 UI**：簡体字中国語、英語、スペイン語、日本語を収録しています。

## 基本操作

1. **画像を開く** を選ぶか、1 枚以上の画像をウィンドウ内の任意の場所へドラッグします。
2. 画像・文字・全画面透かしを追加し、レイヤー一覧で順序と表示状態を調整します。
3. レイヤーを選択して、サイズ、内側余白、不透明度、回転、九点グリッドのアンカーを設定します。
4. 出力形式、品質、任意のリサイズ制限、出力先を選択します。
5. **書き出す** を選択して一括処理を開始します。

## 比率と配置

**視覚比率** は画像の短辺を基準に内側余白を計算するため、横長と縦長で近い見た目の余白を保ちます。内側余白の **パーセント** は対応する幅または高さを基準にし、**px** は固定ピクセル値が必要な場合に使用します。

透かしサイズの **%** は画像の短辺を基準にします。文字透かしでは、描画後の文字全体の長辺を制御するため、文字数が多い場合も意図した視覚比率を保てます。

多くの写真用途では、透かしサイズに **%**、内側余白に **視覚比率** を使用することを推奨します。

全画面透かしでは同じサイズ、不透明度、回転の操作を使い、写真全体に繰り返し配置します。間隔は画像の短辺に対する % で計算され、内側余白と九点グリッド配置は使用しません。

## プリセットと出力パス

プリセットにはレイヤーと書き出し設定の両方が保存されます。既定の保存先は次のとおりです。

```text
%LOCALAPPDATA%\MeiWatermark\
```

各プリセットは独立した `.json` ファイルです。**管理** ボタンでこのフォルダーを開けます。同じ名前で保存する場合は、上書き確認が表示されます。

出力パスを空欄にすると、書き出し前に保存先を選択できます。`/Mei` のような相対パスを指定すると、各元画像の隣に出力先が作成されます。

## 動作環境

- Windows 10 以降
- Python 3.12（ソースから実行する場合のみ必要）

リリース版は単体で動作する Windows 実行ファイルで、Python の別途インストールは不要です。

## ソースから実行

```powershell
conda create -n meiwatermark python=3.12 -y
conda activate meiwatermark
python -m pip install -e .
python -m meiwatermark
```

## 開発とパッケージング

```powershell
# テストを実行
python -m unittest discover -s tests -v

# Windows 実行ファイルをビルド
python -m PyInstaller --noconfirm MeiWatermark.spec
```
